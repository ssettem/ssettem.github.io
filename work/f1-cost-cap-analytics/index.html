F1 Cost-Cap Compliance Analytics

MS CAPSTONE · FORECASTING · PREDICTIVE MODELING
MS Capstone · Lewis University

Formula 1’s cost cap gives every constructor the same spending ceiling, so the question worth asking is whether the cap actually changed how teams spend and perform. For our team capstone on 11 seasons (2015–2025), I led the forecasting and predictive-modeling work, using AI coding tools to build and test the models, then choosing and interpreting the results. The baseline forecast landed at 3.36% MAPE.

What I actually did

01

Forecasting spend

I forecast team spending with ARIMA and ARIMAX time-series models, with the cost cap as an outside factor. The baseline forecast was off by about 3% on average (3.36% MAPE).

02

Testing whether the cap mattered

A Granger causality test checks whether one thing helps predict another. Spending changes helped predict results two seasons later (significant at lag 2, p = 0.02).

03

Testing the model that felt fancier, and not trusting it blindly

A neural network was the obvious “impressive” choice, so I benchmarked it against a Random Forest instead of assuming. With only 11 seasons of data, the Random Forest won (RMSE 103.5 vs 134.7), which is the point of benchmarking rather than picking the trendiest option.

04

A shared data layer

The team built the shared SQL and Tableau data layer together; the forecasting and modeling sections were my part. The code is on my GitHub.
